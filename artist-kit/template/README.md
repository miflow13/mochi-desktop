# Community animation workspace

Use this directory as a clean staging area when creating a Mochi animation. It is intentionally text-only in the repository so artists can copy the canonical master and frames they actually need instead of maintaining duplicate source artwork.

## Suggested local layout

```text
my-mochi-animation/
├── reference/
│   └── mochi_default.png
├── frames/
│   ├── my_animation_01.png
│   ├── my_animation_02.png
│   └── ...
├── preview.gif
└── submission.txt
```

Copy the canonical reference from:

`assets/mochi/master/mochi_default.png`

See [the Artist Kit guide](../README.md) before exporting.
