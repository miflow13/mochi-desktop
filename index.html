What is mochi?

mochi is a handcrafted Linux desktop companion built with Python, GTK4, Cairo, and a lot of tiny handcrafted PNGs.

  • Hand-drawn pixel art and animations.
  • Reacts to typing, terminal use, coding, music, video, idle time, and more.
  • state engine that uses broad desktop signals instead of reading what you type.
  • Built primarily for Fedora GNOME with Wayland/XWayland.
  • Still alpha software! Bugs are part of the deal!!!

Install

On Fedora, clone the repository (this installs current main, not a pinned release):

git clone https://github.com/miflow13/mochi-desktop.git

Then run:

cd mochi-desktop
./install.sh

After installation, open Mochi from the GNOME app grid. You can also run ~/.local/bin/mochi.

The installer may use sudo dnf for missing Fedora packages. On first GNOME Wayland installation, log out and back in once so the desktop-awareness helper can load. Without it, some reactions may be unavailable.

To update, quit Mochi, run git pull --ff-only from your clean main checkout, rerun ./install.sh, then relaunch Mochi.

Status

Stage: early public alpha

Platform: Fedora + GNOME + Wayland/XWayland

Niri is experimental. Other desktops, multi-monitor layouts, and fractional scaling receive less testing.

Known issues remain open: a GNOME Overview/workspace freeze during emotes (#45, alpha blocker) and delayed drag-direction poses (#68, under investigation).

See the alpha QA checklist and release/version notes. This is not a stable release.
