Meet Mochi — a handcrafted Linux desktop companion who wanders, reacts, chats, sleeps, and notices the broad shape of activity around your desktop through privacy-first AmbiSense.

Why Mochi?

A little creature, not another dashboard.

Desktop pets already exist. Mochi is an experiment in making one feel native to Linux: expressive, context-aware, polished, easy to use, and pleasant to leave running. There are no productivity scores, streaks, nagging prompts, or requirements to interact with him.

Handcrafted

Original pixel art and animation drawn frame by frame in Pixelorama.

AmbiSense

A local rule-based awareness system that reacts to broad desktop activity without reading or storing what you type.

Linux-native spirit

Built with Python, GTK4/PyGObject, Cairo, a GNOME Shell helper, D-Bus, Wayland, and XWayland integration.

Privacy first

Awareness without reading your work.

On GNOME, Mochi's Shell helper reduces desktop activity to small semantic signals before they reach Mochi. Keyboard activity becomes an anonymous Pulse over D-Bus — no key symbols, characters, words, or typed content are sent to the app.

Typing

Anonymous activity timing and intensity only. Typed content is never stored or reconstructed.

Context

Applications are reduced to broad categories such as editor, terminal, browser, media, or pixel-art software.

Local behavior

AmbiSense is not an LLM or cloud AI service. It is a lightweight local rule-based behavior engine.

Early public alpha

Bring Mochi home.

Fedora + GNOME on Wayland is the recommended and actively tested environment. The installer handles Fedora dependencies, Mochi's private Python environment, the GNOME helper, app-grid entry, and local launchers. Other Linux setups may work, but support is still broader than the current test matrix.

01

Clone Mochi

git clone https://github.com/miflow13/mochi-desktop.git

02

Run the installer

cd mochi-desktop && ./install.sh

03

Log out and back in once

On first install under GNOME Wayland, this lets GNOME load Mochi's desktop-awareness helper. You do not need to reinstall afterward.

04

Open Mochi

Launch Mochi from the GNOME app grid, or run mochi from a terminal.

Alpha notes

Small support boundary. Useful bug reports.

Mochi is still an alpha. GNOME gets the fullest AmbiSense experience, Niri support is experimental, and mixed monitor layouts, scaling, workspaces, and XWayland behavior can still expose edge cases. If something fails quietly, that is worth reporting too.

Primary target

Fedora Linux + GNOME + Wayland is the main tested environment today.

Still expanding

Broader Linux compatibility, more AmbiSense contexts, and more environment testing are ongoing.

Found something odd?

Open a GitHub issue with your desktop/session, monitor setup, reproduction steps, and any useful terminal output.
